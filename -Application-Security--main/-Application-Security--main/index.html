Project 4: Application Security Guide

This application security toolkit demonstrates secure coding principles and defensive architectures covered in academic coursework:

  • Secure Password Handling: Uses pseudo-bcrypt hashing with random salts to protect stored credentials against rainbow table attacks.
  • Input Validation & Sanitization: Employs regex filters to block malicious SQLi and XSS payloads.
  • Role-Based Access Control (RBAC): Enforces authorization checks before granting access to sensitive resources.
  • Error Handling: Suppresses verbose stack traces to prevent information disclosure.
