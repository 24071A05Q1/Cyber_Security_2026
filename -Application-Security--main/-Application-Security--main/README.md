# AppGuard Security Toolkit (Project 4)

An interactive web application demonstrating application security principles, defensive controls, and vulnerability mitigation techniques for academic lab assessments.

## 🚀 Features
- **Secure Password Hashing:** Demonstrates Bcrypt password salting and work-factor computation.
- **Authentication & MFA:** Simulates secure login with rate-limiting and 2FA token validation.
- **Input Validation & Sanitization:** Tests input payloads against SQL Injection (SQLi) and XSS filtering rules.
- **Role-Based Access Control (RBAC):** Interactive role switcher (Guest, User, Admin) demonstrating authorization checks and access boundaries.
- **Security Headers Checker:** Highlights critical HTTP headers (CSP, HSTS, X-Frame-Options) used for application hardening.
- **Clean Light Theme:** Built with a professional and accessible UI layout.
