# NetPulse IP Range Scanner (Project 3)

A professional web-based Network Security IP Range Scanner designed for academic labs, network discovery practice, and security testing demonstrations.

## 🚀 Features
- **IP Range & Subnet Input:** Supports CIDR notation (e.g., `192.168.1.0/24`) with robust input validation and error handling.
- **Multiple Discovery Modes:** ARP/ICMP Ping Sweep, TCP SYN Port Probing, and Aggressive Discovery.
- **Real-Time Terminal Output:** Live packet logging, status updates, and simulated network response tracking.
- **Interactive Host Discovery Grid:** Visual breakdown of active vs. inactive hosts with detailed inspection cards (MAC address, latency, open ports, OS fingerprinting).
- **Subnet Topology View:** Graphical layout showing connected nodes and gateway status.
- **Export Capabilities:** Download scan reports in JSON format for documentation and lab reports.
- **Clean Light Theme:** Designed with a professional, accessible, and modern light UI.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS (via CDN), Lucide Icons, Vanilla JavaScript.
- **Design:** Responsive dashboard layout tailored for desktop and mobile security audits.
