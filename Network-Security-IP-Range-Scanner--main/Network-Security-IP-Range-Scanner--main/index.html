Project 3: Network Security IP Range Scanner Guide

This web application demonstrates fundamental network discovery principles in a controlled lab environment. Below is an outline of its core architectural components:

  • IP Range & CIDR Input: Validates target subnets before dispatching sweep packets.
  • Host Discovery: Simulates ARP and ICMP echo requests to determine live nodes on the network.
  • Port Probing: Scans common service ports (SSH-22, HTTP-80, HTTPS-443, SMB-445, RDP-3389) on active hosts.
  • Error Handling: Catches malformed IP addresses and alerts users in real-time.
