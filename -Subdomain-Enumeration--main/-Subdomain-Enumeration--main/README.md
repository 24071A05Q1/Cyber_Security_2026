# SubPulse Subdomain Enumeration Toolkit (Project 5)

An interactive reconnaissance prototype built for academic labs to demonstrate subdomain discovery, DNS brute-forcing, and certificate transparency log analysis during authorized security assessments.

## 🚀 Features
- **Target Domain Input:** Supports root domain validation with robust error handling.
- **Multiple Discovery Techniques:** DNS Wordlist Brute-Forcing, Certificate Transparency Search, and Hybrid Multi-Source Reconnaissance.
- **Real-Time Terminal Output:** Live DNS query simulation and response tracking.
- **Discovered Assets Grid & Table:** Categorizes subdomains by IP bindings, HTTP status codes, and discovery sources.
- **Export Capabilities:** Download asset inventories as JSON reports.
- **Clean Light Theme:** Built with a professional, accessible UI.

---

## 🛠️ Tech Stack
- Frontend: HTML5, Tailwind CSS, Lucide Icons, JavaScript.
