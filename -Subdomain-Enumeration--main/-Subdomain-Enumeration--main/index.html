Project 5: Subdomain Enumeration Guide & Explanation

Subdomain Enumeration is a vital reconnaissance phase in security assessments. It helps identify hidden or forgotten assets (e.g., test portals, staging servers, administrative APIs) that expand an organization's attack surface.

How It Works

  • DNS Brute-Forcing: Queries a predefined wordlist of common prefixes (e.g., `www`, `mail`, `api`, `admin`, `staging`, `vpn`) combined with the target root domain.
  • Certificate Transparency (CT) Logs: Searches public SSL/TLS certificate logs (like crt.sh) where domains register certificates for their subdomains.
  • Active vs Inactive Verification: Pings or sends HTTP probes to validated subdomain strings to verify if the server is actively responding.

Error Handling & Robustness

The tool validates domain syntax using Regular Expressions, catches empty or malformed inputs, and provides real-time logging feedback for failed DNS resolutions.
