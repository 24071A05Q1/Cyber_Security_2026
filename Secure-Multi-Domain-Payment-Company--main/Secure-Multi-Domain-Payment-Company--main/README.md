# PayGuard Nexus: Secure Multi-Domain Payment Architecture (Project 6)

A prototype web architecture demonstrating security principles, domain separation, tokenized payment processing, and role-based access control for a multi-domain financial services company.

## 🚀 Features
- **Multi-Domain Separation:** Illustrates isolation across Main Website, Customer Portal, Payment Gateway, Admin Portal, and Backend APIs.
- **Tokenized Payment Gateway:** Simulates PCI-DSS compliant vault tokenization where raw card data is masked and replaced with secure tokens.
- **Authentication & RBAC:** Interactive persona switcher (Customer, Support, Admin) demonstrating authorization boundaries and API endpoint protection.
- **Centralized SIEM Logging:** Real-time audit trail capturing security events and authentication attempts.
- **Clean Light Theme:** Professional enterprise UI design.
